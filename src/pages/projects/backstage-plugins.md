## The Details

This project is a collection of custom plugins for Backstage, developed by
Platacard.

## The Features

The repository currently includes a couple of scaffolder backend-module action
plugins but there are plans to expand significantly in future.

## The Future

We have a number of internally-developed plugins and extensions for Backstage,
and we're going to publish some of them as open-source.
